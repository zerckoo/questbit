SITE SETTINGS

Toggle site-wide features on or off. Changes apply immediately to all players.

AI Verification
When ON, submitted proofs are checked by the AI verifier before rewards are granted. Turning this on disables instant rewards — the instant-reward system stays in place and can be re-enabled when AI is off.
Base URL of the deployed verification backend. Required for AI verification to work; saves on change.
Instant Quest Rewards
When ON, completing a quest awards XP/coins immediately. The proof is still queued for a moderator to review — if rejected, the reward is reversed and the player is notified. When OFF, rewards are only granted after a moderator approves. Disabled while AI verification is ON.
Store Proof Images in Firebase Storage
When ON, proof photos are uploaded to Firebase Storage. When OFF, photos are embedded with the quest entry like thumbnails — no storage used. AI verification always uses Firebase Storage.
